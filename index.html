Abstract

Fault-tolerant multi-UAV coverage missions require mechanisms that jointly handle task redistribution and collision-free trajectory coordination upon disruption. Existing approaches address these requirements in isolation: centralized replanning imposes a sequential pause–replan–resume cycle whose latency grows with fleet size; distributed task allocation leaves transit-path conflicts unresolved after redistribution.

This paper proposes an event-driven distributed coordination architecture in which task reassignment and collision-free trajectory adaptation are activated only upon disruption detection. A single-round parallel auction redistributes affected tasks; a pairwise path-lock protocol resolves transit-path conflicts. Auction planning time remains constant at 204–210 ms regardless of fleet size, while centralized replanning grows to 6.3 s at N = 5. Under multi-UAV failures, the proposed architecture reduces mission delay by up to 48%. Real-hardware experiments with three Crazyflie quadrotors confirm event-driven recovery.

Software Architecture

The system implements a fully decentralised per-drone stack where each UAV runs an identical set of ROS 2 nodes, communicating only through a shared knowledge base and peer-to-peer auction messages — no central planner required.

Resilience Under Disruptions

Four scenarios progressively stress the fleet: single drone failure, multi-drone failure, panel anomaly, and combined failure. Coverage utility is tracked over time across two to five UAVs.

Type I failure

Single Drone Failure

One drone stops operating mid-mission. The Parallel Auction (gold) and CBBA (purple) both recover to near-baseline throughput within ~40 s. The centralized Hybrid (teal) sustains a permanent ~20% throughput deficit from its pause–replan–resume cycle.

Type I × 2

Multi-Drone Failure

Two drones fail sequentially (~20 s apart). The Parallel Auction fully recovers to baseline by t = 60 s, yielding up to 48% mission delay reduction vs. the Hybrid at N = 5. Each failure independently triggers a re-auction with no additional recovery logic.

Type II failure

Multi-Panel Anomaly

One or more solar panels are flagged for re-inspection. A single-panel re-auction dispatches the nearest available drone. The Parallel Auction (gold) maintains near-zero throughput impact — the re-auction overhead is <2 s and the re-assigned panel is a single waypoint.

Type I + II combined

Combined Failure

A drone failure and a panel anomaly occur in the same mission. Both recovery mechanisms activate independently and concurrently — the drone-failure handler and the panel re-auction do not share state. The panel re-auction partially compensates for lost drone capacity.
